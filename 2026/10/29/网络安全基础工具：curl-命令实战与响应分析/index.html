一、 实验背景
curl（Client URL）是一款功能强大的命令行工具，用于在客户端与服务器之间传输数据。它支持 HTTP、HTTPS、FTP、SFTP 等 20 多种协议，是开发者进行 API 调试、网络问题排查和自动化脚本编写的核心工具。

本次实验在 Windows 物理机（CMD 环境） 下进行，通过向真实的互联网站点发送请求，学习并掌握 curl 的基础用法及其核心参数。

三、实验总结
通过本次实验，我掌握了 curl 的三种核心用法：

使用 -A 伪装客户端身份，绕过简单的拦截。

使用 -I 快速探测目标服务器的架构与运行状态。

直接请求 URL 获取完整的网页源码。

curl 虽然只是一行简单的终端命令，但其强大的协议支持和灵活的参数组合，使其成为网络排错、接口测试及安全测试中不可或缺的利器。
